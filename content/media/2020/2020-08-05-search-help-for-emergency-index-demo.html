[key words]

Basics

The simplest way to search Emergency INDEX is to just enter a keyword in the text box above ☝

example: dance will find projects that contain the keyword dance.

multiple keywords

example: dance noise will find projects that contain the keyword dance OR contain the keyword noise.

[ +present -absent ]

Term Presence

To indicate that the keyword must be present it should be prefixed with a plus (+) and to indicate that a keyword must be absent then it should be prefixed with a minus (-). Without either + or - the term will be optional.

example: +dance +noise -duration will find projects that contain the term dance AND noise but will not include any projects that contain the term duration.

[ * ]

Wildcards

Represented as an asterisk (*) that can appear anywhere in the keyword.

example: key* will find projects that contain a keyword that starts with key (e.g. keyword or keyring).

example: *key* will find projects that contain a keyword that contains key anywhere. (e.g. keyword or keyring or monkey or cockeyed etc.).

[ field: keyword ]

Fields

Prefix the search keyword with a name of a filed followed by a colon (:) to find projects that contain the keyword for a specific field.

Available fields

field description
contributor The name(s) of the creator(s) or group
title
content The contributor's description of the performance
place Venue, City, Country (or state) where the first performance occurred
collaborators Names(s) of Other Key Collaborators
home Where are the creators based. City, State (if in the US), and Country (if outside of the US).
tags Terms that the Emergency INDEX editors tagged the project
volume The year (annual volume) the project took place (e.g. 2013)

example: tags:body will find all the projects tagged with body.

example (requiring term presense): tags: body +tags:dance -volume:2011 will find all the projects tagged with body AND tagged with dance but will not include any projects from Volume 2011.
